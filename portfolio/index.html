Featured Architectures

MERN Stack Enterprise Containerization

Transformed a monolithic MERN (MongoDB, Express, React, Node) application into a secure, production-grade cloud-native system.

  • Multi-stage Dockerfiles: Reduced final React static asset sizes by utilizing Nginx alpine-based serving nodes (~8MB) and decoupled TypeScript dependencies from Express runtime images.
  • Unified Ingress Reverse Proxy: Configured an Nginx edge container routing standard requests and Socket.io WebSockets, bypassing all browser CORS configurations completely.
  • Local Compose Isolation: Engineered compose systems with private network bridges and anonymous volumes to prevent local host NPM binary corruption.
  • Infrastructure as Code: Designed a complete, validated Terraform codebase automating VPC subnets, Application Load Balancers, ECS Task definitions, and Fargate clusters.
  • Zero-Trust Subnets: Isolated the ECS tasks inside private, non-routable subnets. The containers only accept network requests originating directly from the ALB's security group.
  • Continuous Deployment: Created a GitHub Actions pipeline using Docker Buildx/QEMU to securely build multi-architecture container images (AMD64 & ARM64) on push to main.
